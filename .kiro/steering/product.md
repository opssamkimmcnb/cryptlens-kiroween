# CryptLens Product Steering

CryptLens is a Haunted Code Archaeologist and Static Complexity Profiler built for the **Kiroween 2026 Hackathon (Costume Contest)**.

## Core Mission
Turn static code quality auditing—typically dry tables of cyclomatic complexity and lint warnings—into an atmospheric, interactive haunted graveyard inspection experience without sacrificing analytical accuracy or developer ergonomics.

## Design Principles
1. **Zero-Setup Instant Execution**: Must run 100% client-side in any modern browser with zero backend or API keys required so judges can evaluate immediately via GitHub Pages or a local static server.
2. **Real Analysis, Not Mock Data**: Every complexity score, nesting depth, smell diagnostic, and call-graph edge must be computed deterministically from the user's actual source code.
3. **Functional Spookiness**: Gothic typography, ectoplasm glow, tombstone nodes, and lantern spotlight effects must actively encode code health (e.g., curse severity colors, pulsing eldritch hotspots, curse-reduction deltas) rather than acting as pure decoration.
4. **Accessible & Ergonomic**: Keyboard shortcuts, clear high-contrast text modes, and opt-in (muted by default) Web Audio sound effects.
